## Why do you need this modpack?

>This GitHub repository has been archived. You can download the latest version of the modpack on Modrinth: Miras's ModPack for phones. However, feel free to report any bugs or issues in the issue tracker.

**MMFP (Miras's modpack for phones)** is designed specifically for smartphones. It optimizes performance and adds convenient, enjoyable mods that improve your Quality of Life (QoL). Every mod is carefully selected to ensure they are not too demanding on phone hardware.

---

## 🚀 Optimization

MMFP optimizes the game for mobile devices, fixing memory leaks and reducing memory consumption to ensure high performance even on low-end smartphones. Installing the game with MMFP also auto-optimizes graphics settings and mod configurations for mobile devices. 
<details>
<summary>Key optimization mods included:</summary>

* **Sodium:** The absolute gold standard for Fabric. It completely rewrites the rendering system, making the game significantly smoother and more responsive.
* **ModernFix + FerriteCore:** Fixes memory leaks and aggressively compresses blockstates and models in RAM, which is critical for smartphones with limited memory.
* **Lithium + ImmediatelyFast + EntityCulling:** *Lithium* fixes server logic and physics in single-player, *ImmediatelyFast* removes vanilla code bottlenecks when rendering text and HUD elements, and *EntityCulling* skips rendering hidden objects. A perfect synergy that eliminates FPS drops.

</details>

> Tested on Samsung Galaxy S24 Ultra: from 74 FPS vanilla → 120 FPS (display cap) with MMFP.

## 📲 Installation guide

Since the modpack is fully optimized for phones, you can download it directly from within the MoJo Launcher app without downloading any third-party files:

1. Open MoJo Launcher (or other good launcher) on your phone.
2. Click the "Create Instance" button.
3. Scroll down to the "Download a Modpack" section.
4. In the search bar, enter the name of this modpack: `Miras's ModPack for phones`.
5. Click the "Install / Download" button. The launcher will automatically configure the correct Fabric version, download all optimizations, and prepare the game for launch!

---

## 💾 Alternative installation method (for other launchers / manually)

If you're playing with other launcher:
1. Download the latest version of the .mrpack file from this Modrinth page.
2. In your launcher, select "Import .mrpack" and select the downloaded file.

⚠️ **Important:** Do not unzip the .mrpack file like a regular ZIP archive; launchers must read it in its entirety.
