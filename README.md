# Miras-s-modpack-for-phones
Optimization mods, as well as QoL mods for a comfortable Minecraft Java Edition experience on your phone using MoJo or other launchers.
## Why do you need this modpack? 
MMFP (Miras's modpack for phones) is designed for smartphones. It optimizes performance and adds convenient and enjoyable mods that improve QoL. Also they are not too demanding on phone hardware (optimized for smartphones).
## Optimization
MMFP optimizing the game for mobile devices, it fixes memory leaks and reduces memory consumption to ensure high performance even on low-end smartphones. Installing the game with MMFP also optimizes graphics settings and mods settings for mobile devices. MMFP includes the following mods:
- **Sodium**: the absolute gold standard for Fabric, rewriting the rendering system, making the game smoother and more responsive.
- **ModernFix + FerriteCore**: fixes memory leaks and aggressively compresses blockstates and models in RAM, which is critical for smartphones that already have limited RAM.
- **Lithium + ImmediatelyFast + EntityCulling**: Lithium fixes server logic and physics in single-player, while ImmediatelyFast removes vanilla code bottlenecks when rendering text and HUD elements. A perfect synergy that eliminates FPS drops.
## QoL
MMFP adds minor features that improve quality of life. This modpack contains mods such as:
- **AppleSkin + Xaero's World Map + Zoomify + LambDynamicLights - Dynamic Lights** (optimized for mobile devices).

Resource packs that improve visuals or make them more user-friendly, such as:
- **Continuity + Low On Fire + Default Dark Mode**. 

And other small mods that improve life without being too demanding on your smartphone's resources.
## Heavy features (Experimental)
Heavy features of MMFP that are disabled beforehand include:
- **BSL Shaders**: beautiful shaders, but it is recommended to use the Low or lower graphics preset on your smartphone. These shaders can also quickly drain your battery and significantly reduce performance, while also heating up your phone, so it is recommended not to use them on low-end devices or if you value your smartphone's battery life.
